## Part 3: Internal Linking Architecture

### 3.1 Link Hierarchy Rules

```
Level 1: Homepage
    ↓ (1-2 clicks)
Level 2: Hub pages (8 total)
    ↓ (1 click)
Level 3: Cluster pages (80-100 total)
    ↓ (1-2 clicks)
Level 4: Sub-cluster pages, glossary terms
```

### 3.2 Required Link Patterns

#### Every Cluster Page Must Include:

1. **Upward link**: Link to parent hub page (first 200 words)
2. **Sibling links**: 2-4 links to related cluster pages
3. **Cross-hub links**: 1-2 links to relevant pages in other hubs
4. **Glossary links**: Link technical terms to /glossary/ definitions
5. **Tool/resource links**: Link to relevant templates/calculators when applicable

#### Every Hub Page Must Include:

1. **All cluster links**: Link to every cluster page in the hub
2. **Cross-hub links**: Links to related hubs
3. **Homepage link**: In navigation/breadcrumb
4. **Tool links**: Links to relevant calculators/templates
5. **Service links**: Relevant commercial pages (where natural)

### 3.3 Anchor Text Guidelines

| Link Type | Anchor Text Approach |
|-----------|---------------------|
| Hub → Cluster | Descriptive, keyword-inclusive |
| Cluster → Hub | Branded or natural ("backlinks guide", "return to hub") |
| Sibling | Partial match or descriptive |
| Cross-hub | Topic-based, natural |
| Glossary | Exact term |
| CTA | Action-based ("download checklist") |

### 3.4 "Suggested Next" Blocks

Include at bottom of every page:

```markdown
## What to Read Next

Based on [current page topic]:
- [Most relevant next step]: [description]
- [Alternative path]: [description]
- [Deeper dive]: [description]
```

### 3.5 Link Density Targets

| Page Type | Internal Links | External Links |

| Hub pages | 15-25 | 3-5 citations |
| Cluster pages | 8-15 | 2-4 citations |
