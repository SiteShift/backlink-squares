## Phase 1: Strategy and Goal Setting

### Define Campaign Objectives

- [ ] Primary keyword targets identified
- [ ] Ranking goals established (current position → target position)
- [ ] Link quantity targets set (realistic based on resources)
- [ ] Link quality standards defined (minimum DA, relevance requirements)
- [ ] Success metrics identified (links, traffic, rankings, conversions)

### Competitive Analysis

- [ ] 3-5 competitors identified for analysis
- [ ] Competitor backlink profiles exported
- [ ] Link gap analysis completed
- [ ] Competitor strategies documented
- [ ] Replicable opportunities identified

### Strategy Selection

- [ ] Primary link building tactics chosen
- [ ] Tactics matched to available resources
- [ ] Timeline for each tactic established
- [ ] Backup tactics identified if primary approaches underperform

**Selected Tactics** (check all that apply):
- [ ] Guest posting
- [ ] Resource page link building
- [ ] Broken link building
- [ ] Unlinked mention outreach
- [ ] Digital PR/content promotion
- [ ] Link reclamation
- [ ] Original research/data studies
- [ ] Other: _________________________________

### Content Preparation

- [ ] Target pages for links identified
- [ ] Landing pages optimised for conversions

### Content Quality Check

For each linkable asset, verify:

- [ ] Comprehensive coverage of topic
- [ ] Accurate, up-to-date information

## Phase 3: Technical Requirements

### Website Technical Health

- [ ] Site loads quickly (under 3 seconds)
- [ ] Mobile-friendly design verified
- [ ] No crawl errors in Google Search Console
- [ ] SSL certificate active (HTTPS)
- [ ] No broken internal links
- [ ] Proper redirect structure in place

### Tracking Setup

- [ ] Google Analytics configured
- [ ] Goal tracking enabled
- [ ] UTM parameter strategy defined
- [ ] Referral traffic tracking verified
- [ ] Ranking tracking configured

### Email Infrastructure

- [ ] Outreach email address set up
- [ ] Email authentication configured (SPF, DKIM, DMARC)
- [ ] Email signature created
- [ ] Test emails sent successfully
- [ ] Email sending limits understood

## Phase 9: Quality Assurance Standards

### Pre-Send Checklist Items

Every email must be verified for:

- [ ] Correct recipient name
- [ ] Correct site/article reference
- [ ] Relevant content pitch
- [ ] Clear value proposition
- [ ] Easy action item
- [ ] Working links
- [ ] No placeholder text remaining
- [ ] Professional signature

### Review Process

- [ ] First 10 emails reviewed by second person
- [ ] Ongoing spot-check frequency defined
- [ ] Feedback loop for template improvements
- [ ] Quality issues escalation process

### Risk Mitigation

- [ ] Backup plans for low response rates
- [ ] Timeline buffers built in
- [ ] Alternative prospect sources identified
- [ ] Budget contingency available

## Quick Reference Summary

### Must Complete Before Launch

1. [ ] Strategy and goals defined
2. [ ] Content ready for promotion
3. [ ] Technical setup verified
4. [ ] Tools configured and tested
5. [ ] Team aligned on process
6. [ ] Prospects identified and qualified
7. [ ] Templates customised and reviewed
8. [ ] Tracking system operational
9. [ ] Quality standards documented
10. [ ] Launch plan finalised

### Common Mistakes to Avoid

- [ ] Starting outreach without enough prospects
- [ ] Using templates without customisation
- [ ] No follow-up system in place
- [ ] Unclear success metrics
- [ ] Inadequate content quality
- [ ] Poor email deliverability
- [ ] No tracking for iteration
