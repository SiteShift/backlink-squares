## Pre-Audit Checklist

### Preparation

**Tools ready**:
- [ ] Google Search Console access
- [ ] Primary backlink tool subscription
- [ ] Spreadsheet software
- [ ] Traffic estimation tool (SimilarWeb)

**Information gathered**:
- [ ] Previous audit reports (if any)
- [ ] Known link building history
- [ ] Competitor list identified
- [ ] Goals and thresholds defined

**Settings configured**:
- [ ] Export permissions verified
- [ ] Time period for analysis set
- [ ] Quality thresholds determined

## Analysis Checklist

### Quantity Analysis

- [ ] Total referring domains recorded
- [ ] Total backlinks recorded
- [ ] Ratio of links to domains calculated
- [ ] Growth trend identified (growing/stable/declining)
- [ ] Velocity assessed (new links per month)

### Quality Analysis

- [ ] Quality tier distribution calculated
- [ ] Average domain authority computed
- [ ] High-value links identified
- [ ] Low-value percentage assessed
- [ ] Quality compared to competitors

### Risk Analysis

- [ ] Spam score flagged links reviewed
- [ ] Toxic links identified
- [ ] Anchor text patterns analysed
- [ ] Unnatural patterns documented
- [ ] Risk level assessed (Low/Med/High)

### Competitive Analysis

- [ ] Competitors' referring domains counted
- [ ] Gap analysis completed
- [ ] Common links identified
- [ ] Opportunity list created
- [ ] Competitive position assessed

## Findings Documentation

### Executive Summary Template

```
BACKLINK AUDIT SUMMARY
Domain: [your domain]
Audit Date: [date]
Period Analysed: [timeframe]

PROFILE HEALTH: [Good/Fair/Needs Attention/Critical]

KEY METRICS:
- Referring domains: [number]
- Average quality (DR/DA): [score]
- Growth rate: [+/- % vs previous]
- Toxic link %: [percentage]

TOP FINDINGS:
1. [Most important finding]
2. [Second finding]
3. [Third finding]

PRIORITY ACTIONS:
1. [Highest priority action]
2. [Second priority]
3. [Third priority]

COMPETITIVE POSITION: [Ahead/On par/Behind] competitors
```

### Detailed Findings Template

**Section 1: Profile Overview**

- Current state of link profile
- Comparison to previous audit
- Notable changes

**Section 2: Quality Assessment**

- Quality distribution across tiers
- Standout quality links
- Quality concerns

**Section 3: Risk Assessment**

- Toxic links identified
- Anchor text issues
- Pattern concerns
- Overall risk level

**Section 4: Competitive Analysis**

- Position vs competitors
- Gap analysis findings
- Opportunities identified

**Section 5: Recommendations**

- Priority 1 actions (immediate)
- Priority 2 actions (soon)
- Priority 3 actions (when possible)
- Ongoing monitoring plan

## Disavow File Template

```

# Created: [date]
# Auditor: [name]
#
# IMPORTANT: This file replaces all previous disavow files
# Always upload complete file, not additions
#
# ============================================
# SECTION 1: PBN Networks
# ============================================

# Identified: [date]
domain:pbn-example1.com
domain:pbn-example2.com

# ============================================
# SECTION 2: Link Farms
# ============================================
# Sites existing only to host links

# ============================================
# SECTION 3: Hacked Site Links

# SUMMARY
# ============================================
# Total domains disavowed: [count]
# Total URLs disavowed: [count]
# Last updated: [date]
```

## Reporting Template

### Report Structure

1. **Cover Page**
   - Domain audited
   - Date range
   - Prepared by
   - Version

2. **Executive Summary** (1 page)
   - Health assessment
   - Key metrics
   - Top findings
   - Priority actions

3. **Methodology** (1 page)
   - Tools used
   - Process followed
   - Thresholds applied

4. **Detailed Analysis**
   - Profile overview
   - Quality assessment
   - Risk analysis
   - Competitive analysis

5. **Recommendations**
   - Prioritised action items
   - Resource requirements
   - Expected outcomes

6. **Appendices**
   - Full data exports
   - Tool screenshots
   - Disavow file
   - Supporting documentation
