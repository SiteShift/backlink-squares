A **do-follow link** (also written as "dofollow" or simply "follow link") is a standard hyperlink that passes link equity (ranking signals) from the source page to the target page. It's the default link type—any link without a `rel="nofollow"` attribute is a do-follow link.

## How Do-Follow Links Work

### The Default State

All HTML links are do-follow by default:

```html
<a href="https://example.com">Link Text</a>
```

This link passes PageRank and ranking signals to example.com. Search engines follow these links and factor them into their ranking algorithms.

### No Special Attribute

Unlike nofollow links, do-follow links don't require any special attribute. They're simply links without nofollow, sponsored, or ugc attributes.

---

## Why Do-Follow Links Matter

### Pass Link Equity

Do-follow links transfer ranking power:

- Help linked pages rank higher
- Build the target site's authority
- Distribute PageRank across the web

### Direct SEO Value

For link building, do-follow links are the primary target because they:

- Count as ranking signals
- Build domain authority
- Help pages compete for keywords

### Natural Link Graph

Do-follow links form the backbone of the web's link structure that search engines use to:

- Discover new pages
- Understand site relationships
- Determine page importance

## Do-Follow vs No-Follow

| Do-Follow | No-Follow |
|-----------|-----------|
| Default link type | Requires rel="nofollow" |
| Passes link equity | Traditionally doesn't pass equity |
| Signals endorsement | Signals non-endorsement |
| Targeted in link building | Often ignored in link building |

### The Evolving Distinction

Since 2019, Google treats nofollow as a "hint" rather than a directive. This means:

- Nofollow links may pass some value
- The distinction is less binary than before
- Both types can contribute to rankings

However, do-follow links remain the primary value-passing link type.

## Identifying Do-Follow Links

### What to Look For

A link is do-follow if it doesn't have:
- `rel="nofollow"`
- `rel="sponsored"`
- `rel="ugc"`

### How to Check

**Browser inspection**:
1. Right-click the link
2. Select "Inspect" or "Inspect Element"
3. Look at the `<a>` tag attributes
4. No rel attribute = do-follow

**Browser extensions**:
- NoFollow extension
- LinkMiner
- SEO toolbars

**Bulk checking**:
- Ahrefs shows link type
- Semrush identifies follow status
- Screaming Frog audits link attributes

## Where to Find Do-Follow Links

### Common Sources

**Editorial content**: Many legitimate editorial links are do-follow

**Guest posts**: Author bio links vary; contextual links may be do-follow

**Resource pages**: Often do-follow when linking to helpful resources

**Business directories**: Quality directories may offer do-follow links

**Press coverage**: News sites sometimes use do-follow for sources

### Common Nofollow Sources

These typically use nofollow:
- Blog comments
- Forum signatures
- User profiles
- Social media posts
- Wikipedia
- Sponsored content

## Do-Follow Link Best Practices

### What to Aim For

**Natural mix**: Not all links should be do-follow. Natural profiles have both.

**Quality sources**: A do-follow from a spam site isn't valuable

**Relevance**: Do-follow from relevant sites > do-follow from irrelevant

**Contextual placement**: In-content do-follow links carry most weight

### What to Avoid

**Do-follow obsession**: Don't ignore good nofollow opportunities

**Buying do-follow links**: Violates guidelines, risks penalties

**Forcing do-follow**: Some sites naturally use nofollow—respect that

**Ignoring link quality**: Do-follow status doesn't make a bad link good

## Common Questions

### Are all do-follow links good?

No. A do-follow link from a spammy, irrelevant, or low-quality site can be worthless or even harmful. Do-follow indicates the link type, not link quality.

### Should I only build do-follow links?

No. Natural link profiles include nofollow links. An entirely do-follow profile looks manipulated. Accept quality nofollow links too.

### Can I tell Google which links to follow?

As a site owner giving links, you can add nofollow. As a link recipient, you can't control whether links to you are followed—that's the linking site's choice.

### Do do-follow links from low-DA sites help?

Potentially, yes. While high-DA do-follow links are more valuable, links from relevant, legitimate lower-DA sites can still help, especially for newer sites.

## Do-Follow Links in Strategy

### Prioritisation

When prospecting, consider:

1. **Relevance** (most important)
2. **Quality/Authority**
3. **Do-follow status** (matters but isn't everything)

A relevant nofollow link often beats an irrelevant do-follow link.

### Tracking

Monitor your do-follow ratio:
- Use backlink tools to see follow vs nofollow
- Compare to competitors
- Aim for natural distribution (typically 60-80% do-follow)

### Outreach Reality

When doing outreach:
- Don't demand do-follow
- Accept whatever link type is offered
- Focus on getting the link, not controlling attributes

## Summary

Do-follow links are standard links that pass ranking signals:

**Key points**:
- Default link type (no special attribute needed)
- Pass link equity to target pages
- Primary target in link building
- Should come from quality, relevant sources

**Remember**:
- Quality matters more than follow status
- Natural profiles include some nofollow
- Don't obsess over do-follow at the expense of relevance

Focus on earning quality links from relevant sources; the follow status will take care of itself.
